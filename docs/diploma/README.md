# Hattama diploma documentation

Development of a Platform for Automated Meeting Minutes Generation in Kazakh and Russian Using Neural Network Models

This package updates the previous proposal around the working Hattama application. The implementation baseline is commit 13d2271. It preserves the existing React/FastAPI/SQLite/local-worker architecture and separates current upload processing from future live ingestion.

[Report](deliverables/Hattama_PreDefense_Report.docx) · [Presentation](deliverables/Hattama_PreDefense_Presentation.pptx) · [Proposal](docs/01-proposal.md) · [Requirements](docs/06-requirements.md) · [References](docs/12-references.md) · [Remaining work](submission/manual-work.md)

The package includes 35 references with eleven scientific publications, three-system comparison, seven technology decisions, 34 requirements, four editable diagrams, evaluation planning and 33 local task records. The application itself is at repository root; follow the root README for setup and testing.

YouTrack is reported created; URL/access unavailable. [Setup guide](planning/youtrack-setup.md) and [backlog](planning/backlog.csv). Illustrative user scenarios and the supervisor-review draft are explicitly labelled; they are not collected testimony or a signed endorsement.

The earlier generic browser simulation and cloud diagrams are superseded by the working application and current architecture diagrams. No production code or model weights are changed by this documentation update.
